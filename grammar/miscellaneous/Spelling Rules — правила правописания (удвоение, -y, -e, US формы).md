Английская орфография кажется хаотичной, но при добавлении окончаний (*-ed, -ing, -er, -est, -s, -es*) она подчиняется небольшому набору правил: удвоение согласной, выпадение *-e*, замена *-y* на *-i*. Эти правила работают в каждом втором предложении, и ошибки в них видны сразу — *stoped, studys, writeing*.

Отдельная тема — различия американского и британского написания. Эта заметка ориентирована на **американскую норму** (*color, center, organize, traveled*): именно она используется в программировании, деловой переписке с США и большинстве онлайн-сервисов. Британские варианты даны для узнавания.

---

#### Удвоение согласной (Consonant Doubling)

Конечная согласная удваивается перед *-ed, -ing, -er, -est*, если выполняются **все три условия**:

```
1. слово заканчивается на ОДНУ согласную
2. перед ней — ОДНА гласная
3. ударение падает на последний слог (или слово односложное)
```

**1. Односложные слова: согласная + гласная + согласная (CVC) → удваиваем**

- stop → stop**p**ed, stop**p**ing — остановить
- plan → plan**n**ed, plan**n**ing — планировать
- big → big**g**er, big**g**est — большой
- hot → hot**t**er, hot**t**est — горячий
- run → run**n**ing, swim → swim**m**ing, sit → sit**t**ing

**2. Две гласные или две согласные → не удваиваем**

- rain → rained, raining (две гласные *ai*)
- look → looked, looking (две гласные *oo*)
- help → helped, helping (две согласные *lp*)
- fast → faster, fastest

**3. Многосложные слова: смотрим на ударение**

Удваиваем, только если ударение на **последнем** слоге.

| Ударение на последнем слоге → удвоение | Ударение не на последнем → без удвоения |
|---|---|
| be**GIN** → beginning | **VI**sit → visiting |
| for**GET** → forgetting | **O**pen → opening |
| ad**MIT** → admitted | **LIS**ten → listening |
| pre**FER** → preferred | **HAP**pen → happened |
| oc**CUR** → occurred | **OF**fer → offered |
| re**FER** → referred | **EN**ter → entered |

**4. Конечные w, x, y никогда не удваиваются**

- show → showed, fix → fixed, play → played

**5. US vs UK: слова на -l**

В американском английском *-l* подчиняется общему правилу ударения (не удваивается в безударном слоге). В британском *-l* удваивается всегда.

| US | UK |
|---|---|
| travel → trave**l**ed, trave**l**ing, trave**l**er | travelled, travelling, traveller |
| cancel → cance**l**ed, cance**l**ing | cancelled, cancelling |
| label → labe**l**ed | labelled |
| model → mode**l**ing | modelling |
| fuel → fue**l**ed | fuelled |

> [!note]
> Исключение в обе стороны: *cancellation* пишется с двумя *l* и в США. А *compel → compelled*, *rebel → rebelled* удваиваются везде, потому что ударение на последнем слоге.

#### Выпадение -e (Silent -e Dropping)

**1. Немое -e выпадает перед гласным окончанием (-ing, -ed, -er, -est, -able)**

- make → mak**ing**, write → writ**ing**, dance → danc**ing**
- nice → nic**er**, nic**est**; large → larg**er**, larg**est**
- love → lov**ed**, lov**able**; use → us**ed**, us**able**

**2. -e сохраняется перед согласным окончанием (-ly, -ment, -ful, -less, -ness)**

- nice → nice**ly**, hope → hope**ful**, care → care**less**
- move → move**ment**, late → late**ness**

Исключения: *true → truly, whole → wholly, argue → argument, due → duly, nine → ninth*.

**3. -ce / -ge сохраняют -e перед -able / -ous, чтобы c и g оставались мягкими**

- notice → notice**able**, manage → manage**able**, change → change**able**
- courage → courage**ous**, outrage → outrage**ous**

**4. -ee, -ye, -oe сохраняют -e перед -ing**

- see → seeing, agree → agreeing, dye → dyeing (красить; сравни *die → dying*), canoe → canoeing

---

#### -y → -ie / -i

**1. Согласная + y → меняем y на i перед -s, -ed, -er, -est, -ly, -ness**

- study → stud**ies**, stud**ied**; carry → carr**ies**, carr**ied**
- happy → happ**ier**, happ**iest**, happ**ily**, happ**iness**
- easy → eas**ier**, eas**ily**; busy → bus**ier**, bus**iness**
- city → cit**ies**, baby → bab**ies**, country → countr**ies**

**2. Гласная + y → y остаётся**

- play → pla**ys**, pla**yed**; enjoy → enjo**ys**, enjo**yed**
- stay → stays, stayed; buy → buys; key → keys; day → days

Исключения: *pay → paid, say → said, lay → laid, day → daily*.

**3. Перед -ing y всегда остаётся (иначе было бы два i подряд)**

- study → study**ing**, carry → carry**ing**, hurry → hurry**ing**

**4. -ie → -ying**

- lie → l**ying** (лежать; лгать), die → d**ying**, tie → t**ying**

#### -s / -es: третье лицо и множественное число

Подробно о множественном числе — в [[Plural Forms — множественное число]]. Правила одинаковы для глаголов (he works) и существительных (books).

| Окончание слова | Правило | Примеры |
|---|---|---|
| большинство | + s | works, plays, books, cars |
| -s, -ss, -sh, -ch, -x, -z | + es | passes, wishes, watches, boxes, buzzes |
| согласная + o | + es (чаще) | goes, does, potatoes, tomatoes, heroes |
| согласная + o (сокращения, музыка, заимствования) | + s | photos, pianos, videos, memos, kilos |
| гласная + o | + s | radios, zoos, videos |
| согласная + y | y → ies | studies, cities, flies |
| гласная + y | + s | plays, days, enjoys |

**-f / -fe → -ves (у существительных)**

- leaf → lea**ves**, knife → kni**ves**, wife → wi**ves**, half → hal**ves**, shelf → shel**ves**, life → li**ves**
- Но: roof → roo**fs**, chief → chie**fs**, belief → belie**fs**, cliff → cliffs, safe → safes

#### i before e, except after c

Школьное правило: «*i* перед *e*, кроме как после *c*» — работает, когда сочетание читается как долгое /iː/.

| ie (обычно) | ei после c | ei со звуком /eɪ/ |
|---|---|---|
| believe, achieve, piece, friend, field, chief, niece | receive, deceive, ceiling, receipt, perceive | eight, weigh, neighbor, vein, freight |

Исключения, которые надо запомнить: **seize, weird, their, height, foreign, leisure, protein, caffeine, either, neither, science** (здесь c + ie, потому что читается не как /iː/).

#### Приставки: без дефиса

Приставки *un-, mis-, re-, dis-, in-, im-, over-, under-, pre-, non-* пишутся слитно, даже если на стыке получаются две одинаковые буквы.

- un + happy → **unhappy**, un + necessary → **unnecessary**
- mis + understand → **misunderstand**, mis + spell → **misspell**
- dis + appear → **disappear**, dis + satisfied → **dissatisfied**
- re + write → **rewrite**, over + rated → **overrated**

**Когда дефис нужен**

| Случай | Пример |
|---|---|
| Приставка перед именем собственным / заглавной буквой | un-American, pre-Columbian |
| Чтобы различить омонимы | re-sign (снова подписать) vs resign (уволиться); re-cover (снова накрыть) vs recover (выздороветь) |
| Традиционно, по словарю | co-worker (но coworker всё чаще), ex-wife, self-esteem, all-inclusive |
| Два одинаковых гласных на стыке (иногда) | anti-inflammatory, re-enter (но cooperate, coordinate) |

Подробнее о дефисах — в [[Punctuation — пунктуация (US)]].

#### US vs UK spelling

| Тип различия | US | UK |
|---|---|---|
| -or / -our | color, favor, honor, humor, neighbor, labor, behavior | colour, favour, honour, humour, neighbour, labour, behaviour |
| -er / -re | center, theater, meter, liter, fiber | centre, theatre, metre, litre, fibre |
| -ize / -ise | organize, realize, recognize, apologize | organise, realise, recognise, apologise |
| -yze / -yse | analyze, paralyze | analyse, paralyse |
| -l / -ll | traveled, traveler, canceled, modeling | travelled, traveller, cancelled, modelling |
| -og / -ogue | catalog, dialog (IT), analog | catalogue, dialogue, analogue |
| -ense / -ence | defense, offense, license (сущ. и глагол), pretense | defence, offence, licence (сущ.) / license (глагол) |
| -e / -oe, -ae | encyclopedia, pediatric, anesthesia | encyclopaedia, paediatric, anaesthesia |
| Отдельные слова | gray, check (чек), program, aluminum, jewelry, tire, curb, mom, pajamas, skeptical, plow, airplane, mustache | grey, cheque, programme, aluminium, jewellery, tyre, kerb, mum, pyjamas, sceptical, plough, aeroplane, moustache |

> [!note]
> Правило одной страны: не смешивайте варианты в одном тексте. Если пишете *color*, то и *organize*, *center*, *traveled*. Выставьте в редакторе язык проверки English (US).

#### Слова, в которых ошибаются чаще всего

| Слово | Подсказка |
|---|---|
| **definitely** | de-FINITE-ly, нет буквы *a* |
| **separate** | there is **a rat** in sep**arat**e |
| **necessary** | одна *c*, две *s*: one Collar, two Sleeves |
| **receive** | ei после c |
| **occurred, occurring** | две *c*, две *r* (ударение на последнем слоге) |
| **recommend** | одна *c*, две *m* |
| **accommodate** | две *c*, две *m* |
| **embarrass** | две *r*, две *s* |
| **tomorrow** | одна *m*, две *r* |
| **beginning** | две *n* (be-GIN) |
| **until** | одна *l* (но *till* — две) |
| **a lot** | всегда два слова |
| **weird** | исключение из i-before-e |
| **grammar** | -ar, не -er |
| **calendar** | -ar |
| **privilege** | нет *d*, нет второго *i* |
| **business** | busi-ness, *i* из *busy* |
| **truly** | без *e* |
| **argument** | без *e* |
| **forty** | без *u* (но *four, fourteen*) |

#### Типичные ошибки русскоязычных

##### Ошибка 1: Нет удвоения в CVC-словах

| Неправильно | Правильно |
|---|---|
| ✗ stoped, stoping | ✓ stopped, stopping |
| ✗ planed (планировал) | ✓ planned (*planed* — строгал рубанком) |
| ✗ biger, hoter | ✓ bigger, hotter |
| ✗ begining | ✓ beginning |

##### Ошибка 2: Лишнее удвоение в безударном слоге или по британской модели

| Неправильно | Правильно (US) |
|---|---|
| ✗ visitting, openning | ✓ visiting, opening |
| ✗ happenned | ✓ happened |
| ✗ travelled, cancelled (в тексте с US нормой) | ✓ traveled, canceled |

##### Ошибка 3: -e не выпадает перед -ing

| Неправильно | Правильно |
|---|---|
| ✗ writeing, makeing | ✓ writing, making |
| ✗ comeing | ✓ coming |
| ✗ nicer → niceer | ✓ nicer |

##### Ошибка 4: -y не меняется на -i (или меняется там, где не надо)

| Неправильно | Правильно |
|---|---|
| ✗ studys, studyed | ✓ studies, studied |
| ✗ citys, familys | ✓ cities, families |
| ✗ plaied, enjoied | ✓ played, enjoyed |
| ✗ studing, carring | ✓ studying, carrying |

##### Ошибка 5: Калька с произношения или с русского

| Неправильно | Правильно |
|---|---|
| ✗ adress | ✓ address |
| ✗ proffessional | ✓ professional |
| ✗ comunication | ✓ communication |
| ✗ apartament | ✓ apartment |
| ✗ wich | ✓ which |
| ✗ alot | ✓ a lot |

##### Ошибка 6: Смешение US и UK в одном тексте

| Неправильно | Правильно |
|---|---|
| ✗ The colour of the center… | ✓ The color of the center… |
| ✗ We organised the program. | ✓ We organized the program. |
