Существительное редко стоит в предложении одно: за ним почти всегда идёт предлог (*reason **for***, *interest **in***), другое существительное (*coffee **cup***, *bus **stop***) или оно само образовано от прилагательного (*the **rich***, *the **unemployed***). Эти связки нельзя вывести логически — предлог после существительного часто не совпадает с русским (*причина чего* — *reason **for***, не *of*), а порядок слов в сочетании «существительное + существительное» обратный русскому (*ключи от машины* — *car keys*).

Здесь три модели: noun + preposition, noun + noun и the + adjective. Все три отличают естественную речь от «переведённой с русского».

---

#### Noun + Preposition

Предлог после существительного обычно совпадает с предлогом после однокоренного глагола или прилагательного (*interested in → interest in*, *depend on → dependence on*), но не всегда. Самые частые сочетания — в таблице; те, что расходятся с русским, выделены в примечании.

| Существительное | Предлог | Пример | Примечание |
|---|---|---|---|
| reason | **for** | What's the reason **for** the delay? | не *of* |
| need | **for** | There's no need **for** panic. | |
| demand | **for** | Demand **for** housing is growing. | |
| interest | **in** | She has a strong interest **in** history. | не *to* |
| increase / decrease / rise / fall / drop | **in** | an increase **in** prices, a drop **in** sales | не *of* |
| change / difference | **in** | a change **in** plans | |
| difference | **between** | the difference **between** A and B | |
| solution | **to** | We found a solution **to** the problem. | не *of* |
| answer / reply / response | **to** | the answer **to** your question | |
| key | **to** | Practice is the key **to** success. | |
| relationship | **with** / **between** | my relationship **with** my boss; the relationship **between** diet and health | |
| connection / link | **between** / **to** | a link **between** smoking and cancer | |
| advantage / disadvantage | **of** | the advantage **of** living downtown | |
| cause | **of** | the cause **of** the fire | |
| example | **of** | an example **of** good design | |
| lack | **of** | a lack **of** time | |
| effect / impact / influence | **on** | the effect **of** stress **on** health | не *to* |
| attitude | **toward** | her attitude **toward** work | AmE *toward*, BrE *towards* |
| reaction | **to** | his reaction **to** the news | |
| access | **to** | access **to** the internet | |
| attention | **to** | pay attention **to** details | |
| damage | **to** | damage **to** the car | |
| invitation | **to** | an invitation **to** the party | |
| trouble / difficulty | **with** | I'm having trouble **with** my laptop. | |
| experience | **in** / **of** / **with** | experience **in** marketing; experience **with** Python | |
| knowledge | **of** | knowledge **of** the law | |
| opinion | **of** / **about** / **on** | What's your opinion **of** him? her opinion **on** the issue | |
| belief | **in** | belief **in** yourself | |
| fear | **of** | fear **of** heights | |
| approach | **to** | a new approach **to** teaching | |
| contribution | **to** | a contribution **to** science | |
| participation | **in** | participation **in** the program | |
| responsibility | **for** | responsibility **for** the project | |
| respect | **for** | respect **for** the elderly | |
| reputation | **for** | a reputation **for** honesty | |
| success | **in** | success **in** business | |

> [!note]
> Расхождения с русским, которые ловят чаще всего: *reason **for*** (причина чего), *solution **to*** (решение чего), *increase **in*** (рост чего), *effect **on*** (влияние на), *interest **in*** (интерес к), *answer **to*** (ответ на), *attitude **toward*** (отношение к). Запоминайте существительное вместе с предлогом как одно слово.

**Toward vs towards**

В американском английском стандарт — *toward* без *-s* (так же *forward, backward, afterward*). *Towards* понятно, но звучит по-британски.

- Her attitude **toward** change is positive. — Её отношение к переменам позитивное.
- We're moving **toward** a solution. — Мы движемся к решению.

#### Noun + Noun (составные существительные)

Первое существительное работает как определение и отвечает на вопрос «какой?». Русский порядок слов обратный: *чашка для кофе* → *coffee cup*; *остановка автобуса* → *bus stop*.

```
[определяющее существительное] + [главное существительное]
     coffee                          cup
```

- a **coffee** cup — чашка для кофе (сравни: *a cup of coffee* — чашка кофе, содержимое)
- a **bus** stop — автобусная остановка
- **car** keys — ключи от машины
- a **shoe** store — обувной магазин
- a **job** interview — собеседование
- a **credit** card — кредитная карта
- the **kitchen** table — кухонный стол
- a **history** teacher — учитель истории
- a **New York** apartment — квартира в Нью-Йорке

**1. Первое существительное — всегда в единственном числе**

Даже если по смыслу их много.

- a **shoe** store (не *shoes store*) — там много обуви
- a **toothbrush** (не *teethbrush*)
- a **car** dealer — продаёт много машин
- **student** loans — кредиты для студентов

Исключения — слова, существующие только во множественном числе, и несколько устойчивых сочетаний: *a **sports** car, a **clothes** store, a **savings** account, **customs** officer, **arms** dealer, **sales** manager*.

**2. Числительное + существительное перед главным словом — в единственном числе и через дефис**

- a **two-hour** meeting (не *two-hours*) — двухчасовая встреча
- a **three-day** trip — трёхдневная поездка
- a **ten-dollar** bill — десятидолларовая купюра
- a **five-year-old** child — пятилетний ребёнок
- a **20-minute** walk — двадцатиминутная прогулка

Сравни без дефиса, когда это не определение: *The meeting lasted two hours. The child is five years old.*

**3. Цепочки из трёх и более существительных**

Характерны для делового и технического английского; главное слово — последнее.

- a **customer service** manager — менеджер по работе с клиентами
- the **health insurance** policy — полис медицинского страхования
- a **data protection** officer — специалист по защите данных

> [!note]
> Больше трёх существительных подряд затрудняет чтение. *The company employee benefits plan review meeting* лучше переписать: *the meeting to review the employee benefits plan*.

#### Noun + noun, 's или of?

Три способа выразить связь между двумя существительными. Подробно о притяжательном падеже — в [[Possessive Case — притяжательный падеж ('s vs of)]].

| Форма | Когда | Пример |
|---|---|---|
| **noun + noun** | тип, назначение, материал; первое слово — категория, не конкретный предмет | a coffee cup, a car door, a paper bag, a kitchen knife |
| **'s** | владелец — человек, животное, организация; иногда время | John's car, the dog's tail, the company's profits, today's news, a week's vacation |
| **of** | часть целого (неодушевлённое), абстрактные связи, длинные фразы | the door of the car, the end of the movie, the top of the page, the beginning of the year |

- the **car door** (тип двери) — **John's** car (чья машина) — the door **of the car** (часть машины)
- a **coffee cup** (чашка для кофе) — a cup **of coffee** (чашка кофе)
- a **wine glass** (бокал для вина) — a glass **of wine** (бокал вина)
- **the company's** decision (кто решил) — the decision **of the board** (длиннее, формальнее)

#### The + Adjective = группа людей

*The + прилагательное* обозначает всех людей с этим признаком. Форма единственная, значение — множественное, глагол — **во множественном числе**.

```
the + adjective  =  all the people who are …
the rich         =  rich people (in general)
```

| Группа | Пример |
|---|---|
| the rich / the poor | The rich **are** getting richer. — Богатые богатеют. |
| the young / the old / the elderly | The elderly **need** more support. — Пожилым нужна поддержка. |
| the unemployed / the homeless | The homeless **were** given shelter. — Бездомным дали приют. |
| the sick / the injured / the disabled | The injured **were** taken to the hospital. — Раненых отвезли в больницу. |
| the dead / the living | We honor the dead. — Мы чтим погибших. |
| the blind / the deaf | Braille helps the blind read. |
| the strong / the weak | The strong **protect** the weak. |

**1. Национальности на -sh, -ch, -ese, -ss**

Прилагательные, которые не образуют множественного числа с *-s*, используют модель *the + adjective*: *the French, the British, the English, the Dutch, the Irish, the Chinese, the Japanese, the Swiss*. Остальные — обычное существительное во множественном: *Americans, Germans, Russians, Italians*.

- The French **are** proud of their cuisine. — Французы гордятся своей кухней.
- The Japanese **have** a long tradition of tea. — У японцев долгая традиция чаепития.
- (но) **Americans love** road trips. — Американцы любят автопутешествия.

**2. Один человек — не the + adjective**

Для одного человека нужно существительное: *a rich man, a poor woman, an elderly person, a Frenchman / a French woman, a blind person*.

- ✗ *He is a rich.* → ✓ He is **a rich man**. / He is rich.
- ✗ *She helped an elderly.* → ✓ She helped **an elderly woman**.

**3. The + adjective в единственном числе: умерший и абстрактные понятия**

- **the deceased** — покойный (один человек, формально; глагол в единственном числе): *The deceased **was** 82 years old.*
- **the accused** — обвиняемый: *The accused **has** pleaded not guilty.*
- Абстрактные понятия (единственное число): *the unknown* (неизвестное), *the impossible*, *the good, the bad and the ugly*: *She fears **the unknown**.*

**4. Прилагательные как существительные в AmE**

В американском разговорном и деловом английском некоторые прилагательные полностью стали существительными с обычным множественным числом: *the locals, the regulars, the professionals, the pros, the greats, the elderlies* (последнее — нестандартно, избегайте). Нормативные: *locals, adults, Christians, Catholics, Republicans, Democrats, liberals, conservatives, intellectuals, criminals, nobles, officials*.

- The **locals** recommended this diner. — Местные посоветовали эту закусочную.
- She's one of the all-time **greats**. — Она одна из величайших за всю историю.

#### Написание составных существительных

Три варианта написания; единого правила нет — проверяйте по словарю (Merriam-Webster для US нормы). Тенденция: чем чаще используется сочетание, тем быстрее оно сливается.

| Тип | Примеры |
|---|---|
| Раздельно (open) | ice cream, bus stop, living room, high school, credit card, real estate, post office |
| Через дефис (hyphenated) | mother-in-law, check-in, well-being, T-shirt, six-pack, know-how, follow-up (сущ.) |
| Слитно (closed) | toothbrush, bedroom, notebook, keyboard, website, email, workplace, airport, database |

Один и тот же корень может писаться по-разному в зависимости от части речи: *to **log in*** (глагол, раздельно) — *your **login*** (существительное, слитно); *to **check in*** — *the **check-in***; *to **set up*** — *the **setup***; *to **back up*** — *a **backup***.

> [!note]
> Множественное число составных: *mothers-in-law* (главное слово — mother), *passersby*, *attorneys general*; но *check-ins, follow-ups, grown-ups* (нет главного существительного внутри).

#### Типичные ошибки русскоязычных

##### Ошибка 1: Предлог из русского после существительного

| Неправильно | Правильно |
|---|---|
| ✗ the reason of the delay | ✓ the reason **for** the delay |
| ✗ interest to history | ✓ interest **in** history |
| ✗ a solution of the problem | ✓ a solution **to** the problem |
| ✗ an increase of prices | ✓ an increase **in** prices |
| ✗ the influence to children | ✓ the influence **on** children |
| ✗ the answer on the question | ✓ the answer **to** the question |
| ✗ attitude to work (понятно, но лучше) | ✓ attitude **toward** work |

##### Ошибка 2: Множественное число у первого существительного

| Неправильно | Правильно |
|---|---|
| ✗ a shoes store | ✓ a shoe store |
| ✗ a two-hours meeting | ✓ a two-hour meeting |
| ✗ a three-years-old child | ✓ a three-year-old child |
| ✗ a books shelf | ✓ a bookshelf |

##### Ошибка 3: Of вместо noun + noun (калька с родительного падежа)

| Неправильно | Правильно |
|---|---|
| ✗ the stop of the bus | ✓ the bus stop |
| ✗ the keys of the car | ✓ the car keys |
| ✗ a teacher of history | ✓ a history teacher |
| ✗ the door of the kitchen | ✓ the kitchen door |

##### Ошибка 4: The + adjective с -s или в единственном числе

| Неправильно | Правильно |
|---|---|
| ✗ the poors, the richs | ✓ the poor, the rich |
| ✗ The rich is getting richer. | ✓ The rich **are** getting richer. |
| ✗ He is a rich. | ✓ He is a rich man. / He is rich. |
| ✗ the Frenchs, the Chineses | ✓ the French, the Chinese |

##### Ошибка 5: Обратный порядок слов в сочетании существительных

| Неправильно | Правильно |
|---|---|
| ✗ a cup coffee | ✓ a coffee cup / a cup of coffee |
| ✗ a station of gas | ✓ a gas station |
| ✗ a store of books | ✓ a bookstore |
