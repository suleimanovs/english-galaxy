> Три жанра, которые нужны на работе и на экзаменах: **отчёт** (структурированные факты и рекомендации), **рецензия** (оценка продукта, книги, фильма) и **пересказ / summary** (сжатое изложение чужого текста без своего мнения). У каждого — своя структура, свой регистр и свои запретные приёмы.

---

#### Business report: короткий деловой отчёт

##### Структура

| Раздел | Что писать | Объём |
|---|---|---|
| Title | Тема + дата (+ автор) | 1 строка |
| Executive Summary | Главный вывод и рекомендация в 3-5 предложениях. Читают все; остальное — не все | 1 абзац |
| Background / Purpose | Зачем отчёт, что анализировали | 1 абзац |
| Findings | Факты, данные, графики. Подзаголовки или нумерация | 2-4 абзаца |
| Recommendations | Что делать. Конкретно, с ответственными и сроками | Список |
| (Appendix) | Таблицы, источники | по необходимости |

> [!note]
> Executive Summary пишется **последним**, но стоит первым. Руководитель должен понять суть, не читая дальше.

##### Фразы по разделам

| Раздел | Фразы |
|---|---|
| Purpose | The purpose of this report is to... / This report examines / assesses / evaluates... / It was commissioned by... |
| Background | Over the past six months,... / Following the launch of..., / The data was collected from... |
| Findings | The results show / indicate / suggest that... / It was found that... / A key finding is that... / Notably,... / Contrary to expectations,... |
| Interpretation | This is likely due to... / This can be attributed to... / One possible explanation is... |
| Recommendations | It is recommended that... / We recommend + -ing / The team should... / Priority should be given to... / Further research is needed to... |
| Conclusion | In summary,... / Overall, the data suggests... / The findings support the case for... |

##### Регистр и пассив

Отчёт пишется формально и обезличенно. Пассив убирает «я» и ставит в фокус факт:

| Разговорно | В отчёте |
|---|---|
| We asked 200 customers. | 200 customers were surveyed. |
| I found that sales dropped. | It was found that sales declined. / Sales were found to have declined. |
| We think it's because of the price. | This is believed to be due to pricing. |
| We should hire more people. | It is recommended that additional staff be hired. |
| A lot of / lots of | a significant number of / a large proportion of |
| get / got | obtain, receive, become |
| big / huge | substantial, considerable, significant |
| sentence contractions (don't, it's) | do not, it is |

Подробнее — [[Formal vs Informal — регистры речи]].

##### Язык данных

| Что | Фразы |
|---|---|
| Рост | increased / rose / grew / climbed **by** 15% (на сколько) / **to** $2M (до какого уровня) / **from** X **to** Y |
| Падение | decreased / fell / dropped / declined by 10% / to 500 units |
| Резко | a sharp / steep / dramatic / significant rise (fall) / rose sharply / plummeted / soared / spiked |
| Плавно | a slight / gradual / modest / marginal increase (decrease) / edged up / dipped slightly |
| Стабильно | remained stable / stayed flat / plateaued / leveled off / held steady at... |
| Колебания | fluctuated between X and Y / was volatile |
| Доля | accounts for 40% of revenue / makes up a third of... / represents the largest share |
| Пик, минимум | peaked at... / reached a high of... / hit a low of... / bottomed out at... |
| Сравнение | compared to / compared with the previous quarter / year over year (YoY) / twice as high as / three times more than |
| Тенденция | an upward / downward trend / is on the rise / is trending down |

```
Revenue increased by 12% to $4.8M in Q2, driven primarily by subscription
sales, which now account for 61% of total revenue. Churn, however, rose
sharply from 3.1% to 4.7%, largely due to pricing changes introduced in April.
```

#### Review: рецензия на продукт, книгу, фильм

##### Структура

| Часть | Что писать |
|---|---|
| Overview | Что это, для кого, в двух словах. Без спойлеров |
| Pros / What works | 2-3 сильные стороны с примерами |
| Cons / What doesn't | 1-2 слабости честно, но не злобно |
| Verdict | Итог + кому рекомендовать + оценка |

##### Фразы

| Часть | Фразы |
|---|---|
| Overview | [Title] is a [genre] by [author] about... / It's aimed at... / I've been using it for three months. / Set in..., the film follows... |
| Pros | What really stands out is... / The strongest part is... / It does a great job of + -ing / I was impressed by... / Where it really shines is... |
| Cons | My main gripe is... / The one thing that let me down was... / It falls short when it comes to... / The pacing drags in the middle. / It's a bit pricey for what you get. |
| Balance | That said,... / On the flip side,... / Despite its flaws,... / It's not perfect, but... |
| Verdict | Overall, it's well worth it. / I'd recommend it to anyone who... / It's a must-read for... / Skip it unless you're a die-hard fan. / Worth every penny. / I'd give it 4 out of 5. / Solid 8/10. / Two thumbs up. |
| Оценочная лексика (+) | gripping, well-paced, intuitive, sleek, reliable, a game-changer, thought-provoking, hands down the best... |
| Оценочная лексика (−) | predictable, clunky, overpriced, underwhelming, buggy, forgettable, a letdown, falls flat |

> [!note]
> В американской рецензии настоящее время для описания сюжета: *The film follows a detective who...* (не *followed*). О своём опыте — прошедшее: *I watched it twice and...*

#### Summary: пересказ и перефразирование

##### Правила

1. **Объём**: примерно треть оригинала или меньше. Абзац → 1-2 предложения.
2. **Без мнения**: только то, что сказал автор. Ваше «я согласен» — не summary.
3. **Своими словами**: не копировать предложения. Менять структуру, не только синонимы.
4. **Первое предложение**: автор + название + главная мысль.
5. **Настоящее время** для текстов: *The author argues...* (текст «говорит» всегда).
6. **Reporting verbs** вместо *says* везде.
7. Не добавлять примеры и детали, которых нет в оригинале.

##### Reporting verbs

| Нейтральные | Утверждение | Аргументация | Критика / сомнение |
|---|---|---|---|
| states, says, writes, describes, explains, notes, points out, outlines | claims, asserts, maintains, contends, insists | argues, suggests, proposes, concludes, demonstrates, shows | questions, challenges, criticizes, dismisses, warns, acknowledges, admits |

##### Шаблон

```
In "[Title]," [Author] argues that [main idea]. [He/She] first points out
that [point 1], then goes on to explain [point 2]. The author also
acknowledges [counterpoint], but maintains that [position]. [He/She]
concludes that [conclusion].
```

##### Перефразирование: как не копировать

| Приём | Оригинал | Перефраз |
|---|---|---|
| Сменить часть речи | Remote work has grown rapidly. | There has been rapid growth in remote work. |
| Актив ↔ пассив | Companies adopted the policy quickly. | The policy was quickly adopted by companies. |
| Разбить / слить | Two long sentences | One short with linking |
| Сменить порядок | Because X, Y. | Y, as a result of X. |
| Синонимы + структура | Many experts believe that... | According to a number of specialists,... |

Копировать можно только термины и имена. Если фраза взята дословно — кавычки.

#### Meeting minutes и action items

```
Meeting: Product Sync
Date: October 3, 2026   Attendees: Anna P., Mark L., Sarah K.

Discussion:
- Q3 results reviewed. Revenue up 12%, churn up — pricing identified as main cause.
- Mark raised concerns about the onboarding flow.

Decisions:
- Pricing change to be rolled back for existing customers.

Action items:
- Anna to draft rollback plan by Oct 10.
- Mark to share onboarding data with the team — Oct 7.
- Sarah to schedule follow-up with sales.

Next meeting: October 17.
```

| Часть | Фразы |
|---|---|
| Что обсуждали | X was discussed / reviewed / raised. / The team went over... / Concerns were raised about... |
| Решения | It was agreed that... / The team decided to... / Approved: ... / Deferred to next meeting. |
| Action items | [Name] to [verb]... by [date]. / Owner: Anna. Due: Oct 10. / Follow up with... / Pending: ... |
| Открытые вопросы | Open question: ... / To be decided (TBD). / Parking lot: ... |

#### Типичные ошибки русскоязычных

| Ошибка | Почему проблема | Что делать |
|---|---|---|
| Копировать предложения из текста в summary | Плагиат; на экзамене — 0 за задание | Перефразировать: структура + синонимы |
| Своё мнение в summary | Summary = что сказал автор, не вы | Мнение — только если задание просит *summarize and respond* |
| *In my opinion I think...* | Дублирование | *In my opinion,...* ИЛИ *I think...* |
| *The author said that...* (прошедшее) | Для текста — настоящее | *The author argues / says that...* |
| *says* везде | Бедно | argues, claims, points out, suggests |
| Summary длиннее трети оригинала | Это уже пересказ, не summary | Одно предложение на абзац |
| Отчёт на «я»: *I found, I think, I recommend* | Слишком лично для формального отчёта | Пассив / *It is recommended* / *The data shows* |
| *Increased on 15%* | Калька с «на» | increased **by** 15% / **to** $2M |
| *Grew up* про цифры | *Grow up* = взрослеть | *grew* / *rose* / *went up* |
| *Very big increase* | Разговорно | *a significant / sharp increase* |
| Рецензия без минусов | Выглядит как реклама | Хотя бы один честный *That said,...* |
| *I recommend you this book* | Ошибка структуры | *I'd recommend this book to anyone who...* / *I recommend it.* |
| Сюжет фильма в прошедшем времени | Нарушение конвенции | *The movie follows... / She discovers...* |
| Action item без ответственного и срока | Не будет сделан | *[Name] to [do X] by [date]* |
| Слишком длинные абзацы в отчёте | Не читают | Подзаголовки, списки, 3-5 предложений |
